🏛️ The 6 Pillars of the AWS Well-Architected Framework

Pillar Core Objective Key Principles on the CCP Exam
Operational Excellence Run and monitor systems to deliver business value and continuously improve. Perform operations as code; make frequent, small, reversible changes; learn from operational failures.
Security Protect data, systems and assets while delivering business value. Principle of least privilege; automate security best practices; protect data at rest and in transit; enable traceability.
Reliability Recover from infrastructure failures and meet demand. Automatically recover from failure; test recovery procedures; scale horizontally; high availability.
Performance Efficiency Use IT resources efficiently to meet architecture requirements. Democratize advanced technologies; go global in minutes; use serverless architectures; experiment more often.
Cost Optimization Avoid unnecessary spend and maximize ROI. Adopt a consumption model (pay-as-you-go); measure overall efficiency; analyze and attribute expenditure.
Sustainability Minimize the environmental impact of running cloud workloads. Understand your impact; maximize utilization; adopt new, more efficient hardware and software offerings.

🧭 The 6 Perspectives of the AWS Cloud Adoption Framework (AWS CAF)

Perspective Main Focus Foundational Capabilities
Business Ensure the cloud aligns with business strategies and goals. Value creation, business case, data monetization, strategic innovation.
People Bridge between technology and business, enablement and organizational culture. Cloud fluency, workforce readiness, transformational leadership.
Governance Orchestrate cloud initiatives and maximize organizational benefits. Portfolio management, program/project management, data curation and KPIs.
Platform Build a scalable, modern hybrid cloud platform. Cloud architecture, data engineering, infrastructure automation and provisioning.
Security Achieve data integrity plus legal and regulatory compliance. Security governance, identity and access management (IAM), data protection, incident response.
Operations Deliver cloud services at the level agreed with stakeholders. Event management, incident and problem management, observability and reliability.

🛡️ AWS Shared Responsibility Model

Layer AWS Responsibility ("OF the Cloud") Customer Responsibility ("IN the Cloud")
Hardware & Facilities Physical security of data centers, servers, cooling, physical network and disk disposal. None (fully managed by AWS).
IaaS (e.g., Amazon EC2, VPC, EBS) Hypervisor, virtualization, physical infrastructure and hardware redundancy. Operating system (OS) installation and patching, Security Groups, host firewall, data and credentials.
PaaS / Managed Database (e.g., Amazon RDS) Host provisioning, OS patching, database maintenance, automated backups. Query optimization, user permission/password management and table encryption.
Serverless / Managed (e.g., DynamoDB, S3) All infrastructure, multi-AZ replication, software and operating system updates. Data classification, permission management (IAM policies / bucket policies) and compliance.

💰 Billing, Cost and Budgeting Tools

Tool When to Use Exam Differentiator
AWS Pricing Calculator Estimate solution costs before deploying or migrating infrastructure to AWS. Public web tool for pre-project planning and simulating future costs.
AWS Budgets Set custom cost, usage and reservation budgets with email/SNS alerts. Sends automatic notifications when actual or forecasted costs exceed the threshold.
AWS Cost Explorer Visualize, understand and forecast historical cost and usage patterns with charts and filters (up to 12 months). Savings Plans recommendations and retrospective spend analysis.
AWS Cost & Usage Report (CUR) The most comprehensive, granular dataset on the cost and usage of every AWS resource by hour/day. Exports CSV/Parquet files to S3 buckets for analysis in Athena/QuickSight.

🔍 Security, Audit and Diagnostics Services Guide

Service What It Does Common Exam Trap
AWS CloudTrail Audits and records API calls and actions taken by users or services across all accounts. "Who did what, when and from where". Does not monitor CPU/memory performance.
Amazon CloudWatch Performance monitoring (metrics, logs, alarms and dashboards) for resources and applications. Infrastructure metrics and billing alarms based on EstimatedCharges.
AWS Config Tracks, audits and evaluates configuration change history against compliance rules. Checks whether resources are compliant (e.g., S3 buckets without public access).
AWS Trusted Advisor Analyzes the environment across 5 pillars: Cost, Performance, Security, Fault Tolerance and Service Limits. Flags unrestricted open ports (0.0.0.0/0) in Security Groups and open buckets.
Amazon Inspector Continuous, automated scanning for software vulnerabilities (CVEs) in EC2, ECR and Lambda. Vulnerability management for operating systems and software packages.
AWS IAM Access Analyzer Analyzes resource policies to identify sharing with external/public identities. Detects whether S3 buckets or IAM roles are exposed outside the AWS Organization.
AWS WAF Web application firewall (Layer 7) that blocks SQL injection and cross-site scripting (XSS). Protects against web exploits on CloudFront, ALB and API Gateway.
AWS KMS Creates and manages cryptographic keys for data encryption (EBS, S3, RDS). Centralized encryption integrated with all AWS services.
